# دليل مشروع الرعاية - نسخة PWA (الإصدار 2.0.0)

## الملفات
- `index.html` : التطبيق كامل (البيانات والتصميم والبحث مدمجة داخله)
- `manifest.json` : بيانات التثبيت (الاسم، الأيقونات، وضع الشاشة الكاملة)
- `sw.js` : يتيح العمل دون إنترنت بعد أول زيارة
- `icons/` : الأيقونات (192 و512 عادية، ونسخ maskable، وأيقونة الآيفون apple-touch-icon.png)

## النشر على GitHub Pages
1. ارفع كل الملفات (وليس مجلد الـ zip نفسه) إلى مستودع `Sami-Sayed-Rizk/MedCare` على الفرع `main` في المجلد الجذر.
2. من Settings ← Pages اختر Source: Deploy from a branch، ثم الفرع main والمجلد `/ (root)`، واضغط Save.
3. بعد دقائق يصبح الرابط: `https://sami-sayed-rizk.github.io/MedCare/`
4. لإصدار جديد: أنشئ Release جديد باسم الإصدار (مثل v2.1.0) واجعله Latest، وغيّر APP_VERSION في index.html ليطابق الرقم. عندها يظهر زر "تحديث الدليل" للمستخدمين الذين يفتحون النسخة القديمة.

## ملاحظات
- التثبيت على أندرويد من Chrome، وعلى الآيفون من Safari (زر المشاركة ⬆ ← إضافة إلى الشاشة الرئيسية).
- عند تعديل الملفات لاحقاً غيّر اسم VERSION في sw.js (مثلاً dulil-raaya-v4) حتى تتحدث الكاش عند المستخدمين.
