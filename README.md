# دليل مشروع الرعاية

دليل مقدمي الخدمات الصحية - نقابة المهندسين المصرية 2026-2027.

نسخة تطبيق ويب (PWA) تعمل من المتصفح وتُثبَّت على الهاتف، وتعمل دون إنترنت بعد أول فتح.

## التشغيل
افتح الرابط من المتصفح، ثم:
- أندرويد: القائمة ⋮ ← "تثبيت التطبيق".
- آيفون: من Safari ← زر المشاركة ← "إضافة إلى الشاشة الرئيسية".
- ويندوز/ماك: أيقونة التثبيت في شريط العنوان ← "تثبيت".
