# دليل مشروع الرعاية - نسخة تطبيق (PWA)

## الملفات
- `index.html` : التطبيق نفسه (ملف واحد يحتوي البيانات).
- `manifest.json` : بيانات التطبيق للتثبيت على الشاشة الرئيسية.
- `sw.js` : عامل الخدمة الذي يتيح العمل دون إنترنت بعد أول زيارة.
- `icons/` : أيقونات التطبيق (الكتاب بالشعار وحواف خضراء ملكية مذهّبة).

## الرفع على GitHub Pages
1. أنشئ مستودعاً جديداً (مثلاً `dulil-raaya`).
2. ارفع كل محتويات هذا المجلد إلى جذر المستودع، أو فك ضغط الملف المضغوط ثم ارفع المحتويات.
3. من Settings > Pages اختر Deploy from a branch ثم الفرع `main` والمجلد `/ (root)`.
4. بعد دقيقة يصبح الرابط `https://<user>.github.io/<repo>/`.

## التثبيت على الهاتف
- Android (Chrome): القائمة ثم "تثبيت التطبيق" أو "إضافة إلى الشاشة الرئيسية".
- iPhone (Safari): زر المشاركة ثم "إضافة إلى الشاشة الرئيسية".

ملاحظة: عامل الخدمة يعمل فقط عبر HTTPS (مثل GitHub Pages)، ولا يعمل عند فتح الملف مباشرة من الجهاز.
